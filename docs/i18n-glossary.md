# Italian glossary

Tuna's Italian uses the informal "tu", like Spotify Italia: short, plain, friendly. Keep these terms
the same everywhere (and the same as Netfish's where they overlap).

| English | Italiano |
|---|---|
| Home / Search / Your library | Home / Cerca / La tua libreria |
| Liked songs | Brani che ti piacciono |
| Playlist / Album / Artist / Song | Playlist / Album / Artista / Brano |
| Queue / Lyrics | Coda / Testo |
| Play / Pause / Shuffle / Repeat | Riproduci / Pausa / Riproduzione casuale / Ripeti |
| Play next / Add to queue | Riproduci come successivo / Aggiungi alla coda |
| Start radio | Avvia radio |
| Follow / Following | Segui / Segui già |
| Get (an album you don't have) | Richiedi |
| On its way | In arrivo |
| Looking | In cerca |
| In your library / Not in your library | Nella tua libreria / Non nella tua libreria |
| Made for you / Discover | Creati per te / Scopri |
| Data saver | Risparmio dati |
| Household | Famiglia |
| Sign in / Sign out | Accedi / Esci |
| Settings / Connections | Impostazioni / Connessioni |
| Administrator / Member | Amministratore / Membro |
| Back / Close / Cancel / Delete / Try again / Save | Indietro / Chiudi / Annulla / Elimina / Riprova / Salva |

Never translate: Tuna, Netfish, Navidrome, Lidarr, Prowlarr, qBittorrent, MusicBrainz, ListenBrainz,
Last.fm, LRCLIB, Subsonic, WireGuard, Portainer, file formats (FLAC, MP3, Opus).
